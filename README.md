# edgeless.technology

This is a curated list of community-focused relay server packages, compatible client-side software, and edgeless tools that support edgeless communities. We also maintain a list of paid service providers capable of integrating with edgeless communities.

## Suggestions accepted:
- Submissions for edgeless compatible software are best submitted as [Issues](https://github.com/Dawn11111111/edgeless.technology/issues).
- Suggestions will be vetted for edgeless community compatibility and reliable functionality. Some suggestive criteria (including, not limited to, not all are required) such as:
  - Configurable home settings for community leaders
  - Focus on personalized, prismatic UX, such as relay views, multiple chats, cross-client/app exploration, etc
  - _or_ tightly restrained to a single, operator-configurable view
  - No global view or public relay feeds as UI filler
  - Controls for variable openness and/or content filters that can be adjusted by operators
  - Interface is _not_ firstly a payment-centric experience, regardless of currency
  - Easily launched, configured, and maintained by everyday people
  - Safe inbox onboarding, and outbox support for any integrated follow feeds
  - Enables users to interact inside one or more various communities at a time
  - Consistent, reliable functionality with tasteful or unique design
  - Out-of-terminal relay/community management and administration, when applicable
  - Available customer service for any suggested service providers
- PRs for software and service listings will not be accepted without prior review.
- Fixes will be accepted for typos & grammatical errors.
- If you wish to contribute further, please comment or reach out.
- If your project is listed, but you would prefer it not be, please reach out or submit a removal PR.
